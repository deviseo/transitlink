# 工具图标的来源

这些 logo 是各个工具或公司的商标，归各自所有，这里只用来标明是哪个工具。

- Claude Code、Codex、Gemini CLI、Grok、OpenCode、DeepSeek、Pi、Kimi、MiniMax、OpenClaw、Antigravity：来自 [LobeHub Icons](https://github.com/lobehub/lobe-icons)（`@lobehub/icons-static-svg` 1.102.0，MIT）。单色的 Grok、OpenCode、Pi、Kimi 另存了一份白色的给深色模式用。
- Oh My Pi：取自 [omp.sh](https://omp.sh) 的网站图标（[oh-my-pi](https://github.com/can1357/oh-my-pi)，MIT），去掉了深色底板。
